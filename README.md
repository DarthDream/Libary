📚 Library Management System

A simple Library Management System developed with Python using Object-Oriented Programming (OOP).

✨ Features

Add Student

Add Book

Search Student by ID

Search Book by ID

Borrow Book

Return Book

Display Books

Display Students

📁 Project Structure

Library/
│
├── libary.py
├── book.py
├── student.py
├── system.py
└── README.md

🛠️ Technologies Used

Python 3

Object-Oriented Programming (OOP)

▶️ How to Run

Clone the repository:

git clone https://github.com/DarthDream/Libary.git

Open the project folder.

Run the application:

python system.py

🎮 Menu

1. Add Student
2. Add Book
3. Search Student
4. Search Book
5. Borrow Book
6. Return Book
0. Exit
